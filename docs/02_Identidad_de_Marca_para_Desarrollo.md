BUBA DRINKS
Identidad de Marca para Desarrollo
Objetivo

Este documento adapta el Manual de Marca a reglas específicas para el desarrollo del sitio web, la experiencia de usuario y el panel administrativo.

Todas las decisiones de diseño, interfaz, animaciones y contenido deberán respetar estas reglas.

En caso de existir un conflicto entre este documento y cualquier otra especificación técnica, siempre prevalecerá la identidad de marca.

¿Qué es BUBA?

BUBA no vende solamente cocktails.

BUBA vende momentos.

El producto es simplemente el medio para crear experiencias.

Cada decisión dentro de la plataforma debe reforzar esta idea.

La web no debe sentirse como un supermercado.

Debe sentirse como el comienzo de una salida con amigos.

Qué debe transmitir la web

Cuando una persona entra al sitio debe sentir inmediatamente:

✔ Marca moderna

✔ Marca premium

✔ Diseño internacional

✔ Producto diferente

✔ Diversión

✔ Confianza

✔ Calidad

✔ Experiencias

Nunca debe sentirse como una tienda genérica.

Personalidad

La personalidad visual debe transmitir:

Cercanía
Energía
Diversión
Modernidad
Lujo silencioso
Simplicidad
Diseño

No queremos exagerar.

No queremos colores chillones.

No queremos una estética infantil.

No queremos parecer una bebida barata.

Regla del Lujo Silencioso

Aunque el producto sea divertido, el diseño de la web debe sentirse elegante.

Las imágenes son las protagonistas.

Mucho espacio en blanco.

Muy poco texto.

Animaciones suaves.

Transiciones modernas.

Nada debe sentirse sobrecargado.

Cómo debe sentirse navegar

El usuario debe sentir que está navegando una marca internacional.

La navegación debe ser:

rápida

simple

clara

fluida

minimalista

Storytelling

La historia de los fundadores no debe esconderse.

Debe existir una sección donde el usuario pueda conocer cómo nació BUBA.

Queremos mostrar que detrás de la marca existen personas reales.

Esto genera cercanía y confianza.

Imágenes

Las imágenes son uno de los activos más importantes de la marca.

Priorizar:

Fotografía profesional

Producto grande

Lifestyle

Amigos

Verano

Playa

Viajes

Juntadas

Momentos espontáneos

Nunca utilizar fotografías genéricas de baja calidad.

Animaciones

Las animaciones deben existir únicamente cuando agreguen valor.

No animar por animar.

Las animaciones deben ayudar a vender.

Colores

Los colores oficiales siempre deberán respetar el Manual de Marca.

Nunca inventar nuevos colores principales.

Nunca modificar el logo.

Nunca alterar la identidad visual.

Tipografías

Respetar siempre las tipografías oficiales.

No incorporar nuevas familias tipográficas sin justificación.

Redacción

Todo el contenido de la web debe escribirse respetando el tono de la marca.

Debe sentirse como una conversación.

Nunca como un texto corporativo.

Qué NO queremos

No queremos una tienda de Shopify.

No queremos una plantilla.

No queremos una página llena de banners.

No queremos sliders infinitos.

No queremos veinte colores.

No queremos exceso de texto.

No queremos popups molestos.

No queremos parecer una marca barata.

Cómo tomar decisiones

Si existen varias alternativas de diseño, siempre elegir la que mejor represente estos valores:

Elegancia

Simplicidad

Confianza

Diversión

Calidad

Modernidad

Regla de Oro

Ante cualquier decisión de diseño, preguntarse:

¿Esto ayuda a que BUBA parezca una marca internacional preparada para competir con las mejores marcas de bebidas del mundo?

Si la respuesta es "no", debe buscarse otra solución.

Checklist obligatorio

Antes de aprobar cualquier pantalla verificar:

Respeta el branding.
Respeta el manual de marca.
Se siente premium.
Es fácil de usar.
Se entiende en menos de cinco segundos.
Está optimizada para mobile.
Refuerza la personalidad de BUBA.
