BUBA DRINKS
Principios de UX y Diseño
Objetivo

Este documento define los principios de experiencia de usuario (UX) y diseño (UI) que deberán respetarse durante todo el desarrollo de la plataforma.

Estos principios aplican para:

Sitio web
Ecommerce
Panel administrativo
Landing Pages
Blog
Checkout
Futuras aplicaciones

Toda decisión visual deberá respetar estas reglas.

Filosofía

La web debe sentirse como una marca internacional.

Queremos que un usuario pueda pensar:

"Esta marca parece mucho más grande de lo que realmente es."

No buscamos una web llamativa.

Buscamos una web elegante.

Simple.

Rápida.

Premium.

Con personalidad.

Menos es más

Cada elemento que aparece en pantalla debe tener un propósito.

Eliminar cualquier elemento innecesario.

Antes de agregar algo preguntarse:

¿Aporta valor?
¿Ayuda a vender?
¿Mejora la experiencia?
¿Reduce la fricción?

Si la respuesta es "no", no debe existir.

Mobile First

Toda pantalla deberá diseñarse primero para celular.

Luego tablet.

Luego desktop.

Nunca al revés.

La mayoría de nuestros clientes descubrirán la marca desde Instagram, TikTok o Meta Ads utilizando su teléfono.

Velocidad

La velocidad forma parte del diseño.

Una página lenta transmite una mala imagen.

Objetivos:

Carga inicial menor a 2 segundos.
Lighthouse superior a 95.
Core Web Vitals en verde.
Optimización automática de imágenes.
Lazy Loading donde corresponda.
Claridad

El usuario nunca debe preguntarse:

¿Dónde hago clic?
¿Qué tengo que hacer?
¿Cómo compro?

Todo debe ser evidente.

Navegación

La navegación debe ser extremadamente simple.

Máximo tres clics para llegar a cualquier sección importante.

No crear estructuras complicadas.

Jerarquía visual

Cada pantalla debe tener una jerarquía clara.

Producto
Beneficio principal
Botón principal
Información secundaria
Información complementaria

Nunca competir por la atención del usuario.

Llamados a la acción (CTA)

Cada sección debe tener un único objetivo.

No utilizar múltiples botones principales en la misma sección.

Siempre debe quedar claro cuál es la acción esperada.

Ejemplos:

Comprar ahora
Ver sabores
Conocer la historia
Agregar al carrito
Espacios

Utilizar espacios amplios.

No sobrecargar la pantalla.

El espacio en blanco transmite calidad.

Tipografía

Priorizar la legibilidad.

Nunca utilizar textos demasiado pequeños.

Mantener una jerarquía consistente de títulos y subtítulos.

Imágenes

Las imágenes venden más que el texto.

Siempre priorizar:

Fotografías reales.
Lifestyle.
Personas disfrutando.
Producto protagonista.
Alta calidad.

Evitar imágenes genéricas.

Animaciones

Las animaciones deben ser elegantes.

Nunca exageradas.

Nunca molestas.

Deben ayudar a comprender la interfaz y aportar dinamismo.

Scroll

El usuario debe querer seguir bajando.

Cada sección debe generar curiosidad por la siguiente.

Conversión

Todo debe estar pensado para vender.

Antes de diseñar una pantalla preguntarse:

¿Esta pantalla ayuda a que el usuario compre?

Si la respuesta es no, rediseñarla.

Confianza

El usuario debe confiar en la marca desde los primeros segundos.

Mostrar:

Métodos de pago.
Envíos.
Opiniones.
Seguridad.
Historia de la marca.
Redes sociales.
Storytelling

No vender únicamente una bebida.

Vender una historia.

Vender una comunidad.

Vender una experiencia.

El producto debe sentirse como parte de algo más grande.

Productos

Los productos siempre son protagonistas.

Las fotos deben ocupar mucho espacio.

El usuario debe entender el producto sin leer demasiado.

Checkout

El checkout debe ser extremadamente simple.

La menor cantidad posible de pasos.

No pedir información innecesaria.

Reducir al máximo el abandono del carrito.

Panel Administrativo

El panel debe seguir exactamente la misma filosofía.

No debe sentirse como un software complejo.

Debe ser intuitivo incluso para alguien sin conocimientos técnicos.

Accesibilidad

Todo el sitio debe ser accesible.

Buen contraste.
Navegación con teclado.
Etiquetas correctas.
Formularios claros.
Botones grandes.
Consistencia

Todos los botones deben comportarse igual.

Todos los formularios deben funcionar igual.

Todas las tarjetas deben compartir el mismo estilo.

Toda la plataforma debe sentirse como un único producto.

Regla del "Apple Test"

Antes de aprobar cualquier pantalla preguntarse:

Si esta pantalla estuviera en la web de Apple, ¿parecería fuera de lugar?

Si la respuesta es sí, debe rediseñarse.

Regla del "5 segundos"

Un usuario nuevo debe entender en menos de cinco segundos:

Qué vendemos.
Qué hace diferente a BUBA.
Qué tiene que hacer.
Cómo comprar.
Errores

Los errores deben ayudar al usuario.

Nunca mostrar mensajes técnicos.

Siempre explicar:

Qué ocurrió.
Por qué ocurrió.
Cómo solucionarlo.
Estados de carga

Nunca mostrar pantallas vacías.

Utilizar skeleton loaders.

Mostrar feedback inmediato en todas las acciones.

Diseño para escalar

Todo componente debe diseñarse pensando en el futuro.

Hoy existen cuatro productos.

Mañana pueden existir cien.

El diseño nunca debe depender de la cantidad actual de contenido.

Principio de confianza

En cada página el usuario debe sentir que está comprando en una empresa seria, profesional y estable.

No queremos transmitir la imagen de un emprendimiento pequeño.

Queremos transmitir la imagen de una marca con potencial internacional.

Regla Final

Cada decisión de UX y diseño debe responder afirmativamente a estas preguntas:

¿Es más simple?
¿Es más rápida?
¿Es más clara?
¿Genera más confianza?
¿Hace que el producto se vea mejor?
¿Aumenta la probabilidad de compra?
¿Respeta la identidad de BUBA?

Si alguna respuesta es negativa, la solución debe replantearse.
