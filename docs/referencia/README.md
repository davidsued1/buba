# Referencia: plugin de Fast Mail para WooCommerce

Código oficial del plugin de Fast Mail / e-Presis para WooCommerce, tal como
lo envió Fast Mail. **No se usa en la web**: está acá como referencia de cómo
se habla con la API de Presis (`includes/api/sdk-epresis.php`).

No contiene claves. El token de la cuenta va solo en Vercel.
